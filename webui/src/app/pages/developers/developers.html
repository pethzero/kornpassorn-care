ภาพรวม

API นี้สำหรับ ระบบ (เซิร์ฟเวอร์ แอป หรือสคริปต์) ไม่ใช่บัญชีผู้ใช้ของคน — แต่ละระบบได้ Client ID และ Client Secret จากผู้ดูแลคลินิก

Client IDรหัสประจำระบบ (เปิดเผยได้) เช่น kpc_3f9a…
Client Secretเหมือนรหัสผ่าน — เก็บที่เซิร์ฟเวอร์ ใช้ แค่ตอนขอ token ห้ามใส่ในแอปมือถือ/หน้าเว็บ
Access Tokenบัตรผ่านอายุ 1 ชั่วโมง ส่งไปกับ ทุก request ใน header Authorization: Bearer …

เริ่มใช้ใน 3 ขั้น

  1. ขอ Client ID + Secret จากผู้ดูแลคลินิก (เมนู API Clients) พร้อมบอกว่าต้องการสิทธิ์อะไร
  2. แลก Access Token ที่ POST /oauth/token
  3. เรียก API พร้อม header Authorization: Bearer <access_token> — token หมดอายุ (401) ก็ขอใหม่

POST /oauth/token

แลก Client ID + Secret เป็น Access Token (OAuth2 client_credentials) — รับ JSON, form-urlencoded หรือ HTTP Basic

fieldค่า
grant_typeclient_credentials
client_idClient ID ที่ได้รับ
client_secretClient Secret ที่ได้รับ
ใช้ token ซ้ำ — token อายุ 3600 วินาที เก็บไว้ใช้จนใกล้หมดแล้วค่อยขอใหม่ ไม่ต้องขอทุก request

ข้อมูลส่วนบุคคล

  • API ส่งเฉพาะ รหัสคนไข้ + ชื่อต้น + อักษรแรกของนามสกุล — ไม่มีเบอร์โทร เลขบัตรประชาชน ที่อยู่ หรือหมายเหตุภายใน
  • เก็บ Client Secret ในเซิร์ฟเวอร์ (environment variable / secret manager) เท่านั้น ถ้าหลุดให้แจ้งคลินิกสร้าง secret ใหม่ทันที
  • คลินิกปิดสิทธิ์ client ได้ทุกเมื่อ — token ที่ออกไปแล้วใช้ไม่ได้ทันที
